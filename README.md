# STK SDC Round 1

STK Pilot in Krasnodar, Russia: Systeme Electric Drift Challenge Round 1, converted for Live for Speed.

## Credits

- Original Assetto Corsa track: **HighSpeedGarage**
- FBX source and LFS conversion work: **Unry Works**
- LFS packaging: **lfs-track-builder**

## Install

Install through Live for Speed's **Get mods** browser, or extract `stk_sdc_round_1.zip` into the LFS installation folder. The archive contains the track folder at its root.
